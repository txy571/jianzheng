# 意识形态测试 — 先锋主义 SPA 设计文档

## 概述

部署到 GitHub Pages 的单页意识形态测试应用。100 道题映射到 5 个坐标轴（经济、外交、国家机构、社会文化、科技），通过加权李克特量表评分，使用加权欧几里得距离匹配 100 种意识形态。先锋主义视觉风格，含动态 Canvas 背景和 CSS 故障动画。

## 技术栈

- **单文件 `index.html`** — 无构建步骤，无框架
- **Tailwind CSS** — CDN 加载
- **Chart.js** — CDN 加载，用于结果雷达图
- **Vanilla JS** — 所有逻辑、状态管理、Canvas 特效
- **数据文件**：`questions.json`、`ideologies.json` — 运行时通过 `fetch()` 加载

## 数据架构

### 题目 (`questions.json`)

约 140-150 道题，每道包含：
- `id`: 1-N
- `text`: 中文题目
- `weights`: 5 个轴的权重对象（`econ`、`diplomatic`、`state`、`society`、`tech`），取值范围 -2 到 +2

题库来源：
- 原文档 100 题为主体（重新分配 5 维多轴权重）
- 精选 CNValues 约 40-50 道高质量题目补充
- 去除语义重复题目
- 大量题目设计为多轴权重，增强区分度

### 意识形态 (`ideologies.json`)

100 种意识形态，每种包含：
- `id`: 1-100
- `name`: 中文名称
- `nameEn`: 英文名称
- `category`: 1-8（意识形态聚类编号）
- `coords`: 5 轴坐标对象（百分比 0-100）
- `description`: 中文简述

### 5 个坐标轴

| 轴 | 低分 (0%) | 高分 (100%) |
|------|---------------|-------------------|
| econ | 市场 | 平等 |
| diplomatic | 全球 | 国家 |
| state | 自由 | 权威 |
| society | 进步 | 传统 |
| tech | 技术加速 | 技术控制 |

### 意识形态 8 大聚类

1. 马克思列宁主义与威权共产主义
2. 社会民主主义与左翼自由意志主义
3. 自由主义与进步主义
4. 中间派与融合政治
5. 保守主义与右翼秩序派
6. 自由意志主义与无政府资本主义
7. 法西斯主义与极端威权
8. 边缘理论与缝合型向量

## 评分算法

### 原始分

```
S_axis = Σ(weight_i,axis × multiplier_i) 对所有 100 题 i
```

李克特 5 点乘数：
- 非常同意: +1.0
- 同意: +0.5
- 中立: 0.0
- 不同意: -0.5
- 非常不同意: -1.0

### 归一化

```
P_axis = round( (S_axis / M_axis) × 100 )
```

其中 `M_axis = Σ|weight_i,axis|`（该轴理论最大绝对值总和）。

### 意识形态匹配

加权欧几里得距离（各轴权重 ω 均为 1）：

```
D = sqrt( Σ(P_k - I_k)² ) 对 k in [econ, diplomatic, state, society, tech]
```

最小距离 D 为最佳匹配。显示前 3 名。

## UI 结构

### 第 1 页：首页

- 全屏 Canvas 背景：漂浮几何体（三角形、圆形），缓慢旋转和颜色渐变
- 中央标题 "意识形态测试"，带 CSS 故障动画（定时 RGB 分离）
- 副标题："100 题 · 5 维坐标 · 精准政治光谱定位"
- 大号 "开始测试" 按钮，霓虹 hover + CRT 扫描线揭示效果
- 底部简短说明

### 第 2 页：答题

- 顶部：脉冲发光效果的进度条
- 当前题号：先锋大字体 "14 / 100"
- 题目卡片：高对比背景，CSS grain 纹理
- 5 个李克特按钮：红色(-) → 灰色(0) → 绿色(+) 渐变色阶，波浪式 hover 动画
- 上一题/下一题导航
- 题目卡片切换时带偏移/故障 CSS 过渡
- Canvas 背景继续但变暗

### 第 3 页：结果

- Chart.js 雷达图，先锋风格定制（霓虹色深色背景、无填充、粗线条）
- 图表从 0 动画到最终值
- "最佳匹配" 部分：意识形态名称大字体（支持故障效果），打字机动画逐字显示
- 描述段落
- 下方列出前 3 名匹配
- "重新测试" 按钮

## 评分流程

```
用户点击答案 → 更新 5 个运行总分数 → 下一题
→ 第 100 题完成 → 归一化到 -100..100 每轴
→ 计算到所有 100 种意识形态的距离 → 按距离排序
→ 渲染雷达图 + 前 3 名匹配
```

## 动态视觉元素

1. **Canvas 背景**：`requestAnimationFrame` 循环绘制旋转几何体，颜色在酸性调色板中渐变插值
2. **故障效果**：CSS `@keyframes` 定时对标题文字施加 `transform: translate()` + `clip-path` + text-shadow RGB 分离
3. **按钮波浪**：李克特按钮 hover 时通过 `transition-delay` 交错产生波浪效果
4. **卡片过渡**：旧卡片滑动/故障消失，新卡片偏移进入
5. **CRT 扫描叠加**：半透明重复线性渐变模拟扫描线
6. **打字机效果**：结果页意识形态名称逐字显示

## Q&A

问：为什么不用 React/Vite？  
答：GitHub Pages 零构建部署更简单，加载更快，单 HTML 文件的先锋约束本身符合反建制美学。

问：多轴权重如何分配？  
答：天然跨越多个维度的话题（如互联网审查 = 国家 + 科技；UBI = 经济 + 科技；基因编辑 = 社会 + 科技）在多轴上获得非零权重。
